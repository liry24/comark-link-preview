Comark link previews

Each stock Comark renderer uses plugins: [linkPreview(options)]. The async plugin waits for metadata and returns complete HTML nodes. Deterministic source chunks, delays, errors, edits, and cancellation run entirely against local fixtures; example.test is never contacted.
